## 已确认并修复

| 问题 | 修复与回归证据 |
| --- | --- |
| 隐藏或移除节点时，有限动画调用 `commitStyles` 会抛出异常，可能中断会话清理并触发重连 | 共用动画停止函数对隐藏/脱离节点使用 `cancel()`；隐藏节点不启动动画。进入设置时停止不可见刷新动画，返回时按请求状态恢复。浏览器测试覆盖更新、隐藏、重置和设置切换。 |
| 设置阈值无效时，“返回”被表单校验阻止 | 返回提交按钮使用 `formnovalidate`；合法保存仍保留原校验。隔离测试与当前实机静态交互均通过。 |
| 等待 Web Lock 的旧提醒，在会话重置或重新注入后仍可能发出 | 用会话清理代次和已释放标记淘汰旧回调；同账户收到新数据也不能使旧回调重新有效。 |
| 很长的合法 `Retry-After` 超过浏览器定时器上限，可能形成立即执行循环 | 限制每次 `setTimeout` 的等待长度，保留原冷却截止时间；不提前发请求。 |
| 安装失败后的旧重试计时器，在重新注入后可能恢复旧实例，产生重复入口 | 清理时取消安装重试；回调检查实例是否已释放。 |
| `auth.json` / `config.toml` 被改名移走时，监听器只看新文件名，可能继续保留旧会话 | 两个配置监听路径复用同一个判断，同时检查改名前后路径；一次事件只失效一次。 |
| Helper 和 Python 配置发现忽略 `CODEX_HOME`，可能读取默认目录中的另一账户 | Helper 的读取和监听共用配置根目录；Python 保留显式参数优先级。指定目录缺失时不回退默认凭据。 |
| Python 兼容路径接受 NaN、Infinity 或无法转成有限浮点数的大整数 | 共享有限数值校验覆盖官方窗口和 API 金额，保留布尔值、范围及时间校验。 |
| Python 独立 API 卡把剩余 80/100 画成 20% | 剩余行直接使用剩余比例。此处属于保留的 Python 兼容路径，桌面活动数据链仍是 C#。 |
| 开发用计划任务脚本可能覆盖/删除仅名称相同的其他任务 | 修改前检查根任务目录、单一 action、完整程序路径、工作目录和空参数；16 个隔离场景覆盖匹配与拒绝路径。 |

`CODEX_HOME` 的范围是 Helper 自身进程环境。另一个客户端私有的环境变量无法由计划任务自动推断；两者应继承相同配置。没有新增跨进程环境读取或持久化目录覆盖。

## 动画与加载优化

额度条更新改为先设置最终宽度，再用原生 `transform: scaleX()` 从当前显示长度过渡到终点；中途更新从当下视觉长度继续。保留最小填充和真实比例，不再每帧动画化 `width`。

首次挂载先完成布局，再建立宿主观察器。观察器保存已测量的锚点矩形，忽略没有尺寸变化的首次 ResizeObserver 通知，避免重复挂载及过早结束刚启动的展开动画。实际几何、主题和可见性变化仍响应。

构建复用已安装的 esbuild 压缩空白和语法，保留源码标识符与许可证；两份部署脚本写入规范化源码的 SHA-256，便于检查是否过期。没有新增运行依赖。

### 对比测量

环境：Headless Edge、DPR 1.25、合成 Plus 样本。交替运行旧版与当前版各 8 轮，排除首轮，以下为各 7 次样本的中位数。额度更新统计窗口为更新后约 260ms。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 部署 JS 字节数 | 149,466 | 127,662（减少 14.6%） |
| 首次挂载宿主选择器查询 | 6 | 2 |
| 首次挂载布局计算次数 | 6 | 4 |
| 首次挂载样式重算次数 | 15 | 11 |
| 一次额度更新期间布局计算次数 | 53 | 9（该场景减少约 83%） |
| JS 首次注入执行时间 | 24.1ms | 24.0ms |
| 展开动画初始化执行时间 | 13.1ms | 13.2ms |

可以确认脚本体积和渲染负担降低；首次注入、展开的执行时间没有明显改善。这不是客户端完整冷启动测量，也不是合成器帧率测量，不能据此宣称稳定 60/120fps。

本机复现：设置下述 `NODE_PATH` 后运行 `node .runtime-test/audit-20260929/compare-performance.cjs`。原始样本位于 `.runtime-test/audit-20260929/performance-comparison.json`，基线保存在该目录的 `before/`。这些临时证据保留在本项目工作区，不作为分发包依赖。

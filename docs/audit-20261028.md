## 确认并修复的问题

| 范围 | 触发与影响 | 修复与证据 |
| --- | --- | --- |
| 首次统计页动画 | 骨架生成晚于页面动效测量，结束时高度突然增长 | 在测量前生成首载状态；同一复现的顶部跳变从 164px 降至小于 0.001px。 |
| 动画中的统计回包 | 打开途中收到结果后，目标高度仍是旧值 | 立即更新内容并从当前画面重新设定动效目标；253px 跳变降至小于 0.001px，保留当前高度方向的速度。 |
| 内部过渡中返回／收起 | 先结束内部高度动画，再启动外层退场，丢失中间状态 | 将当前可见高度交给外层动效；边缘及标题的跳变由约 27.7px 降至约 0.013px。 |
| 图表缩放 | 窄列仍保留 7 列和旧选中坐标，底色偏离日期柱 | 仅在图表实测宽度变化时重排 5／7 列并重算选中标记；39px 偏移归零，保留所选日期与键盘焦点，不新增查询。 |
| 独立会话漏算 | 不同会话恰好同时间、同累计计数，被全局事件键合并 | 按明确 thread 身份区分消费；合成用例由错误的 110 token 恢复为 220 token。归档副本、明确父历史、嵌套历史和继承启动快照仍正确去重。 |
| 超大日志尾行 | 超过 16MiB、尚未换行的 token 事件未被标记为不完整 | 保留超长行前缀判定，未终止 token 行如实标记 partial；普通聊天／工具长行不冒充额度缺失。 |
| PowerShell 5.1 诊断 | CDP 目标数组被包成嵌套数组，多个 WebSocket 地址拼在一起 | 正确逐个解析目标；多目标回归覆盖 5.1 与 7，实机两者均为 Active。 |
| 重复点击当前页 | 无变化点击仍重建每日按钮并启动 15 个动画 | 同页操作保留 DOM，仅处理必要的焦点和日历关闭；不再创建这些动画。 |
| 重复读取日志 | 每份未变化日志仍打开解析流并分配 64KiB 缓冲区 | 保留长度、修改时间、创建时间和尾部锚点验证，确认 EOF 无变化后直接返回；未完成尾行仍继续处理。 |
| 柱状图布局开销 | 逐柱插入、测量、写动画起点，反复触发布局 | 批量构建、测量、写入，再启动动画；保留中途高度／透明度及退场柱子的连续性。 |

另修正了启动回归夹具的过期方法截取边界，并对后台快捷方式监视器使用会在误入时失败的隔离替身。该夹具先因编译缺失类型失败，修正后 17 组通过；没有为了让测试通过而改变生产启动逻辑。

## 性能测量

| 场景 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 1000 个未变化小日志，5 轮交错暖查询中位耗时 | 141.25ms | 83.25ms，降低约 41.1% |
| 上述每次查询的 64KiB 输入缓冲区分配 | 1000 次／62.5MiB | 0 次 |
| 7 根非零柱翻页的 LayoutCount | 20 | 8，减少 60% |
| 同一图表场景 6 轮同步处理耗时中位数 | 约 2.7ms | 约 2.2ms |

日志两组夹具均返回 1000 个事件；缓冲区指标仅统计这类输入数组，不代表进程总内存或总分配量。冷启动完整扫描未作性能收益承诺。

部署后在当前前台 Codex 窗口采样空闲、同页点击、每日页、详情页、快速反向、折叠明细、返回和外层反向等 8 个场景，每个约 850ms。各场景 RAF 帧间隔 P95 约 4.3ms，最大观测值 29.2ms；没有超过 33.4ms 的帧间隔或超过 50ms 的长任务。场景结束后活动动画和临时图层均为 0。

这是整个宿主渲染页面的短时 RAF 观察，不是独立合成器 FPS 测量，也不能保证所有显示器、后台负载与长时间使用下均不掉帧。

轨迹与层次背景和套餐纵向使用 1 − (1 − p)³；主数字横向分段推进，并沿路径轻抬至多 12px 避开细条；% 独立缩放；新增内容在 p > .85 后渐显。共享元素始终保持身份；空背景缩放时补偿圆角，禁止整体面板连同文字一起缩放。
反向与原生生命周期从同一原生时钟读取当前进度与 spring.velocity(t)，重定向到新目标；原生 display/overlay 关闭绘制保留 700ms。原生 popover 在退出动画结束前就会退出命中，不能让它与原入口同时禁用。关闭中原入口 pointer-events:auto、tabIndex=0，下一次点击或 Space/Enter 立即重新打开并反向。取消前解除旧 onfinish，并校验本次播放身份；保留 beforetoggle/微任务/toggle 的开启时序，不能用延迟 hidePopover 破坏外部关闭或原生菜单互斥。
数据更新与清理动画使用完整可视 payload 签名；账户切换、数据变化、重注入、隐藏、减少动态效果和几何变化均有清理路径。隐藏或脱离节点的有限动画与循环动画使用 cancel()，避免 commitStyles 异常；进入设置停止不可见转子，返回后按请求状态恢复。不修改请求侧 quotaUsageFingerprint 的额度变化语义；纯文字和侧栏轨道模式不虚构共享数字或时间环。
宿主观察器首次布局完成后再订阅锚点，保存已测矩形；没有几何变化的首次 ResizeObserver 通知不重渲染或结束展开动画。继续过滤同值属性、字符与文本替换。真实主题、样式或可见性变化仍响应；不针对某个扩展 ID 绕过观察，也不更改宿主组件。
间距：8px 主节奏卡片左、上、下内边距 8px；正文另缩进 8px，形成距外壳 16px 的共同左边界。正文右内边距 16px，头部右侧按固定箭头锚点留位。主副行网格、头部工具与设置分组间距均 8px。8 / 16 / 24 / 32 用于空间组织；紧凑入口、徽章和图标内部的微间距是明确的光学校正例外。不能把字号、描边、圆环、宿主测量值强行凑成 8 的倍数。
对齐：共同基准线标题、窗口标签、主数字、末行重置信息左对齐；两枚工具图标在相同 16px 画布、24px 点击区域内居中；设置按钮与固定收起箭头共用竖向中心轴。横条与数字并列时按同一行组织；对齐不等于把所有元素堆到左侧。固定箭头与头像的宿主实测对齐优先。positionPopover 复用收起按钮横坐标和标题区真实右边界计算 --cq-control-right。头部通过正常内边距留位，不使用负外边距；不移动底部箭头。
层级：额度优先主额度数字 20px/600；次级 5h 与标题 13px；时间与语义标签 11px muted；套餐徽章 9.5px/600。依据任务重要性分配大小和颜色，不机械放大标题。本控件的主额度是视觉焦点；弱化信息仍需可读，错误状态保持明确。
16px 工具图标刷新、设置、成功与失败四枚 SVG 按 16×16 坐标重新绘制，描边 1.5px、圆端点；按压用底色反馈。此前是 Lucide 24px 图形缩小至 15px；现在不再缩放头部细线图标。侧栏仪表已在 2026-10-05 按 20px / 1.33px 重绘并绑定剩余额度；固定 Chevron 继续复用已有图形。
刷新动画与交接独立 HTML 转子承载原生 transform 旋转：900ms/圈、linear。静态刷新、转子、成功、失败四层固定叠放，以 140ms opacity 交叉淡入淡出。刷新完成时旋转继续到不可见后才 cancel，避免角度归零闪跳；同一次刷新重渲染不重置时钟。快速响应不人为延迟，减少动态效果/隐藏/关闭立即清理。原请求、限流与失败语义不变。
无可见滚动条正常额度卡的 scrollWidth=clientWidth、scrollHeight=clientHeight；卡片与设置均不显示滚动条。取消工具区域的负外边距，避免浏览器把右侧留白计入滚动范围。极短窗口仍允许滚轮与键盘访问设置内容，scrollbar-width:none；禁止用裁掉内容冒充无溢出。
额度更新过渡先设置最终宽度，再以 transform:scaleX 从当前显示长度过渡到终点，200ms；transform-origin:0 50%。中途更新承接当前视觉长度，不再每帧修改 width。真实比例、最低填充与减少动态效果语义不变。
状态与重注入边界旧安装重试在清理时取消；旧排队提醒按实例与会话清理代次失效；无效阈值不阻止返回。保留账户隔离；长 Retry-After 分段等待，不改变服务端冷却截止时间。

从早期验证稿到最终生产实现：技术取舍与入口

保留 JavaScript/CSS、原生 popover、现有 Motion spring 与 Lucide。没有为动效迁移到 React/SwiftUI，也没有新增依赖。早期 shared-motion-study-20260927.html 使用 MotionValue 在 JavaScript 中逐帧写样式，参数 damping=40；它是历史机制实验，不能作为最终实现或性能基线。

实机剖析显示逐帧样式写入会唤醒宿主观察链，移除 blur 未解决该开销。最终使用 spring.next/velocity 预计算轨迹，交给原生 WAAPI 播放，并过滤无实际变化的宿主通知。空背景使用独立 transform；新增内容只做 opacity 渐显。

代码定位：native-patch/native_patch.source.js 中的 animateSharedPopover、finishSharedPopover、positionPopover、ensureShell 与 observeOfficialCards。运行验证：node --test tests/native_patch_runtime.cjs；构建一致性：npm run build:check。

刷新图标的精细度与流畅度是两个独立问题：16px 专用路径改善小尺寸外观；原生 HTML transform 层和 opacity 交接避免逐帧写样式及切换图形时的角度跳变。循环动画及隐藏/脱离节点上的有限动画均使用 cancel()；不可见节点不启动新动画。代码入口：toolIcons、refreshMotion、setRefreshButtonState、createRefreshButton。

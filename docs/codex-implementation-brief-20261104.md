## 3. 视觉规格

### 3.1 几何

| 项 | 值 |
|---|---|
| 浮层宽 | 260 CSS px（当前宿主实测值，**从宿主几何读**，不写死） |
| 面板圆角 | 20 |
| 内边距 | 12（左右对称） |
| 同心阶梯 | 20 → 8（轨道、日历、输入组）→ 6（按钮、输入）→ 4（格、色块、柱） |
| 柱图高 | 46 |
| 主读数记号 | 40 × 9 |

同心圆角的规则是：**每一级圆角 = 上一级 − 自己的内边距**，不是随手写的几个数。

### 3.2 字阶

| 角色 | 字号 / 字重 |
|---|---|
| 主读数数值 | 21 / 600，letter-spacing −0.024em，`font-variant-numeric: tabular-nums` |
| 主读数标签 | 10.5 |
| 次读数数值 | 13.5 / 600 |
| 次读数标签 | 10.5 |
| 行文字 / 详情 | 10.5 |
| 图例 | 9.5 |
| 日标 | 9 |

光学修正（必须做，不然左缘看起来不齐）：

- 主读数 21px 负字距后 `margin-left: −0.012em`，让视觉左缘回到与标签同一条竖线
- 次读数值 `margin-left: −0.008em`
- 色块、转圈、记号、开关圆点各 `translateY` 0.5–1px，落在 x 高度中心而不是盒子中心

### 3.3 颜色

中性走 Radix **sand** 12 级，按级别用，不按喜好用：

| 级别 | 用途 |
|---|---|
| 1 | 应用底 |
| 2 | 浮起面（面板） |
| 3 | 内嵌、轨道 |
| 4 / 5 | 悬停 / 按下 |
| 6 / 7 / 8 | 细分隔 / 边框 / 强边框 |
| 12 / 11 | 主文字 / 次文字 |
| 10 | 只给非文字（日历里的上/下月日期等） |

数据三色（只做色块，**不上文字**，读数一律 ink 层级）：

| 数据 | 浅色 | 深色 |
|---|---|---|
| 非缓存输入 `--cq-chart-input` | `#D8DCE0`（sand 系外的 slate 6） | `#4A5058` |
| 缓存输入 `--cq-chart-cache` | `#30A46C` | `#30A46C` |
| 输出 `--cq-chart-output` | `#0D74CE` | `#70B8FF` |

警示只用 red：文字 `#CE2C31`（深 `#FF9592`），底 `#FEEBEC`（深 `#3B1219`），边 `#F4A9AA`，实心 `#E5484D`。

**三条硬规则**

1. 同一种颜色在整个界面里永远只表达同一种数据。
2. 非缓存是浅灰，浅灰**只能做柱顶的「盖」，不能做柱底** —— 它对面板底色只有 1.31 的对比度，贴底会整段隐形、柱子显矮。
3. 因此每日柱**自下而上**是：缓存（绿）→ 非缓存（灰）→ 输出（蓝）。这是对文档里「非缓存/缓存/输出」语义顺序的**有意偏离**，理由就是第 2 条，别改回去。构成三段横条仍按 非缓存 / 缓存 / 输出 左到右；它最左端的浅灰用一圈 1px `--cq-border` 细边兜住。

输出色**不要**用 blue 9 `#0090FF`：它压在绿上只有 1.03 的明度差，输出只占 6%，那根细边会消失。`#0D74CE` 对绿 1.51，能读。

深色下 `--cq-chart-*` 走 `#codex-quota-popover[data-cq-dark]` 作用域，和现在一样。

## 4. 结构与行为

### 4.1 主页面（自上而下）

1. 顶行：统计符号 + 「本机用量」+ 齿轮（右侧）
2. 页签：今日 / 本周 / 自选，**滑动指示块**（`left` 插值，不重建节点）
3. 区间行：`11-02 00:00 — 11-04 18:42` + 右侧「3 天」
4. 两个主读数，**上下堆叠**（不并排），每个两行：
   - 第一行：10.5 标签 + 右侧固定 40×9 记号
   - 第二行：21/600 数值
   - 本机估算用「两端有界」的区间记号 + `≈ 1.80–2.20%`；账号变化用「两点之差」的箭头记号 + `+6.0 百分点`
5. 次读数两列：总 token / API 等值（13.5/600），上方 1px 细分隔
6. 每日柱图（多日范围才有；单日不画孤立柱）+ 图例（必须有文字）
7. 消耗构成（默认折叠）
8. 按模型（默认折叠）
9. 脚注：结果时间 + 「口径说明」

**两个主读数不许并排**：21px 数字并排时，`≈ 1.80–2.20%` 与 `+6.0 百分点` 会互相挤压，只能靠缩字号解决，那是错的。长数字与范围要允许换行：在破折号之后放 `<wbr>`，让 `≈ 1.80–` / `2.20%` 按上下界分组断开。

主读数旁边**不再**写「Token 1.80% · API 2.20%」这类口径行 —— 口径拆到设置里。旁边只留必要语义（采样起止、含其他设备、跨重置、已校正、部分计价、仅 Token 口径）。

### 4.2 每日柱图

- **本周固定七格**：一 二 三 四 五 六 日。
- 有日志：正常堆叠柱（自下而上 缓存 / 非缓存 / 输出）。
- 本周内无日志：柱位留空 + 基线上 2px 虚线短桩。**「没有记录」≠「确认零消耗」**，不能画成同一个东西。
- 未到的日子：柱位留空、基线 45% 透明、日标降一级灰、`pointer-events:none`、不是按钮。
- 单日范围不画柱（没有对比价值）。
- 点某天只更新「该日 token / API 等值」这一行，**不发请求**、不改主读数的区间。
- 区间首尾两天只统计实际选中的时段。
- 柱外轮廓 4px 圆角，段与段之间不留缝，由父级 `overflow:hidden` 裁出；选中柱用 ink 58% 的 1px 描边、offset 1px。

### 4.3 时间

- 今日 = 本地 00:00 至此刻；本周 = 本地周一 00:00 至此刻；自选 = 任意起止。
- 今日/本周刷新时结束时刻跟随当下；自选提交后**保留绝对端点**，不滑动。
- 自选编辑器：开始/结束日期+时间（秒级）、自绘日历、`5/10/30/60min` 快捷、起止滑块收在「精细调整」里、明确的「应用」。
- **编辑只是草稿**：拖滑块、选日历、点快捷时长都不查询，点「应用」才提交。
- 所有读数、构成、模型、日图必须同一个精确区间 `(start, end]`。
- 读新范围期间可保留上次结果，但**必须保留它原本的结果时间**；未提交的草稿不能冒充旧结果的归属。

### 4.4 设置

低频内容全部进设置：Pro 参考套餐（`$100 / $200 / $500`，用户此前用 `Pro $200 · 20x`，属用户选择不是默认）、周额度基准、Token/API 拆分、ModelDial 核对状态与来源、API 价格来源、口径与限制、低额度与恢复提醒偏好、自检与诊断、版本与说明。

设置体要高可滚、**无可见滚动条**（`scrollbar-width:none` + `::-webkit-scrollbar{width:0}`），进/出用 260ms 高度过渡，切换前先量旧高、结束清理 inline 样式。

## 5. 状态清单（14 个都要能出现）

1. 首次读取骨架（每行与真实行等高，数据回来不跳版）
2. 已有结果时刷新（旧数字不动，状态行转圈，脚注保留原结果时间）
3. 首次失败（给原因 + 重试 + 自检，不要只有一个感叹号）
4. 刷新失败但保留旧结果（失败是一条细提示，不把面板变成错误页）
5. 无记录（不是 0）
6. 没有可比基准
7. 未选 Pro 档位
8. 部分模型可折算 / 可计价（「2 / 3 个模型可比」「部分 API 等值」）
9. 采样不足两点（不可用，不能填 0）
10. 部分覆盖（保留数值 + 显示真实采样起止）
11. 采样有间断
12. 跨重置（不能简单相减）
13. 官方计数已校正 / 下降
14. 极长数字与 >100% 估算（不截断，允许换行）

## 6. 动效契约

- 开、合、展开、收起随时可打断并反向，从**当前可见值**继续，不能先跳回起点。
- 材质与内容一起出入，不留白色空壳。
- 高度变化、设置返回、日图更新连续。
- 不缩放文字（不要用 `scale` 制造模糊）。
- 动画期间不锁按钮。
- 结束清理临时样式与图层（`height` / `clipPath` / `transform` / `opacity` 归空，`getAnimations()` 归 0）。
- 遵守 `prefers-reduced-motion`（降为 0.001ms 或直接跳）。
- 窗口进后台停止无意义动画。

`assertMotionClean()` 就在测这些，别让它红。

## 8. 做法建议

- 分步改，一步一提交：① token 与几何 ② 主页面读数区 ③ 柱图与七天帧 ④ 折叠区 ⑤ 设置 ⑥ 编辑器 ⑦ 动效。每步都让 `build:check` 与测试绿。
- 样式走现有路子：`native-patch/tailwind.css` 的 `cq:` 工具类，或 `ensureStyle()` 里的注入样式；**不要新建 CSS 文件**。
- 注意 `build_ui.mjs` 有断言：`tailwind.css` 里禁止出现 `:root` / `:host` / `@property` / 全局 `*`。所以 token 只能挂在 `#cq-local-usage` 这类局部作用域上，不能放 `:root`。
- 所有新文案都走 `words(zh, en)`，中英同时给，不要只写中文。
- 不要顺手重排无关代码，不要全局格式化。diff 应该只覆盖本机用量浮层的渲染层。

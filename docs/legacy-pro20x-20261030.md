# 旧 Pro 20x 与 Token／API 双口径估算

2026-10-30 实现并部署，尚未发布 GitHub。

OpenAI 的 [2026-10-29 公告](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)取消了 Pro $200 的额度减半调整；原高额度用户保留原额度。按用户确认，估算中的 Pro $200 选择现明确对应旧 20x，不再使用 ModelDial 的较低“新额度”行。

## 周参考与截图单位

截图中的 36.81／207.24 亿 Token、$5,691／$4,083 是图表的月值，不可直接作周分母。ModelDial 的[公开订阅数据](https://modeldial.com/subscriptions?period=week&view=insights)及其[页面数据资源](https://modeldial.com/_next/static/chunks/1le8xgox6o_u-.js)提供了独立命名的 `weekly_tokens` 与 `weekly_api_equivalent_usd`；当前读取这些字段，不从 URL 的 period 参数猜测图表口径，也不再将旧值乘二或除二。

| 模型 | 周 Token 参考 | 周 API 等值参考 |
| --- | ---: | ---: |
| GPT-6 Astra | 849,560,154（约 8.50 亿） | $1,313.419998084 |
| GPT-6.1 Sol | 4,782,528,501.084447（约 47.83 亿） | $942.1581147136362 |

源数据的月／周比例是 52／12；把截图月数当作周参考会使周消耗比例低估约 4.33 倍。以上是第三方样本／推导参考，不是 OpenAI 公布的固定 Token 上限；分数 Token 来自外推，不表示日志计数允许分数。

## 计算与展示

用户选择双口径参考范围。对同一批有参考的模型分别计算：

- Token 口径：`T = 100 × Σ(模型本机总 Token ÷ 模型周 Token 参考)`。
- API 口径：`A = 100 × Σ(模型本机 API 等值 ÷ 模型周 API 等值参考)`。
- API 等值沿用已有公式：普通输入为输入减缓存读写，分别按普通输入／缓存读取／缓存写入／输出单价计价；推理 Token 不再额外加到输出。写入保留时长未知时沿用 30m／12h 两端价格，得到 `A_low / A_high`。
- 展示范围：`[min(T, A_low), max(T, A_high)]`。按模型归一化后相加，不把不同模型的参考总量直接相加，不把 T 与 A 相加或取平均。

本次重新核对 [OpenAI Standard 短上下文价格](https://developers.openai.com/api/docs/pricing)，Astra／Sol 6.1 的普通输入、缓存读取、输出及两档缓存写入单价与已有快照一致。API 等值不是实付账单，不含长上下文、加速、地区或工具附加费。

今日、本周、自选日期及任意时间区间均使用同一计算函数。主读数显示参考范围；详情增加“估算拆分”，保留日期查询和已查询时间区间各自的 Token／API 读数。范围端点与百分号成组换行，避免窄侧栏中单位单独占一行。估算依据展示每个模型的周 Token／USD 两个分母及来源。

两口径并非独立观测。旧 Sol 的 Token 参考本身就来自 API 等值与固定缓存比例的换算，Astra 的两项参考同样关联于样本负载。范围只表达两种口径的差异，不是置信区间，不保证真实账号扣量位于其中，也不宣称合成后已获得统计精度提升。

## 缺失与隔离

只有相同覆盖模型集合的两口径才组成范围。缺少可比 USD 基准或 API 单价时明确标“仅 Token 口径”，不能拿一部分模型的 API 百分比与另一批模型的 Token 百分比拼范围。无基准模型仍计入 Token 明细、单独提示不参与估算；缺日志、缺缓存写入计数、部分模型等限制继续明示。没有记录保持未知，不用 0 冒充；真实零读数可为 0。跨多周的统计可以超过 100%。

官方额度卡和账号实测仍来自原有官方链路。此估算只进入统计页，不覆盖官方横线、时间圆环或官方账号采样，也不以多设备账号总差值拟合本机的权重。

## 每日更新与快照

保持已有每 24 小时的持久检查频率，尝试时间先于 HTTP 写盘，升级、失败和 Helper 重启都不绕过。当前读取一次公开 HTML 和一个同站数据资源；资源限定于页面唯一订阅模块引用的 `modeldial.com/_next/static/chunks/` 白名单路径，最多 8 个候选，成功即停。每个响应限长与超时，不执行下载的 JavaScript，不发送凭证、账号或用量。

旧档强制校验提供商、Pro 20x、$200／USD、历史标记及明确的周字段；独立保存旧档成功时间。现代套餐 HTML 检查成功不能冒充旧档更新成功。失败保留上次确认的旧数据和时间；还没有成功旧档缓存时使用已核实的 2026-10-30 周参考快照，显示 `snapshot`，`lastSuccessAt=null`，检查失败另作提示。绝不退回较低的新 Pro 200 基准。

本机升级时原每日冷却尚未到期，因此实机暂显示明确快照，等既定时间再自动核对。为验证读取器，在隔离测试目录执行了匿名公网读取：HTML 1 次、数据资源 1 次，周 Token／USD 与上表匹配；未改生产缓存或其冷却时间。

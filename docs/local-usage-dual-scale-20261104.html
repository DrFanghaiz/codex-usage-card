两种刻度

为什么不能相减

1.80–2.20% 是两种口径各自算完后的最小到最大，不是置信区间，也不保证官方真实扣量落在里面；6.0 百分点 是两个官方采样点之间的差，包含这台电脑以外的设备。

较长历史的累计估算可能超过 100%，那时折行，不截断、不缩字号。

状态

同一套骨架，文字与记号在换

每一张都是 1:1 的 260px 面板。行高、基线、列宽不动——变的是文字、记号、以及该出现的提示。

设置页

低频内容集中在此，高度变化连续

齿轮进入、返回回到主页面，面板高度用 260ms 过渡，不跳。设置只影响参考基准与提醒，不碰统计算法。

Pro 档位显式选。$100 / $200 / $500 是三种周基准，猜错差 2.5 倍。
基准可核对。ModelDial 同步时间就在旁边。
提醒留在入口原位。不生成独立弹窗；系统通知默认关闭。
自检给结论不给日志。失败直接写哪一项断了。

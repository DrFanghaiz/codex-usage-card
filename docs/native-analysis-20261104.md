# v2.7 本机用量入口

2026-11-04。官方已提供账号额度及分析页面，本项目收敛为本机用量分析。v2.7.0 发布版同步更新 Helper 和安装器版本，并校验发布包。

## 入口与浮层

- 只有一个插件符号，始终位于官方额度按钮上方。沿用侧栏单色、20px 光学尺寸的线性图标，使用柱形统计符号区分官方额度圆环，不再展示套餐和剩余额度。
- 从真实底部按钮组定位头像及官方额度 SVG；不依赖中文文案、生成的类名或截图坐标。官方按钮尚未出现时挂在头像上方，出现／替换后移至官方按钮之前；不创建列表 footer。
- 点击直接打开右侧本机用量浮层，默认收起；没有旧额度主页面或独立应用窗口。列表展开、收起、裁剪及亚像素残留不会切换挂载模式。
- 本机当前官方菜单实测宽 260 CSS px、圆角 20px。双刻度改版的浮层采用经确认的 Sand 浅深实底与细外边；保留宿主字体及阴影关系。官方菜单可见且与额度按钮可访问关联匹配时读取真实宽度并缓存，首次菜单尚未出现时沿用宿主 spacing ×65。打开时读取实际入口矩形并限制在视口内；详见[当前统一页面与验收](unified-usage-20261104.md)。这些是当前宿主测量记录，不是所有版本的固定接口。
- 弹层采用与官方相同的短距离右侧浮出关系，不再从列表底部条形变。完整材质与文字共同淡入淡出，不缩放文字；沿用现有 spring／WAAPI，途中可点击关闭、反向重开。Escape 回到入口；外部点击保留点击目标焦点。减少动态效果时即时完成。
- 日期、滑块、区间查询和详情仍在同一浮层内；小窗口仅内容滚动，无可见滚动条。官方菜单与插件面板通过原生菜单的外部点击及 Popover light-dismiss 互斥。

## 信息层级

当前实现以[统一用量主页面](unified-usage-20261104.md)为准：只有今日／本周／自选三个时间选项，无四个内容页签。主页面突出本机额度估算与账号百分点变化，其次为 token 和 API 等值；多日图、构成及模型沿用同一精确查询范围，后两项按需展开。参考套餐和口径统一移至设置。

前一轮[信息审查记录](ui-information-audit-20261104.md)按原日期保留；其中“参考估算不在主位”“构成／详情页”的结构已被本轮用户确认的新方案取代。

## 保留的边界

不隐藏、替换或改变官方额度组件，不再覆写 Statsig。热升级清除旧的原生卡隐藏标记；旧进程中已安装且无法还原的历史 Statsig 包装需等待客户端自然重载消失，不为此关闭用户窗口。

沿用现有 Helper、请求限流、网络设置、账号隔离、持久采样、日志去重及增量扫描。刷新本机日志不增加官方请求；不上传会话正文、日志或采样。API 等值仍是价格折算，不是实付账单。升级不删除历史、参考缓存或用户配置。

Doctor 识别 `data-cq-kind="local"`，同时兼容旧 `official`。入口真实可见即健康，面板默认收起及官方额度暂时失败不影响安装判定。不得仅因官方原生图标可见就判插件正常。

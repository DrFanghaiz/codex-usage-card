# v2.2.0 发布验证

2026-09-28。当前外观与实现参数见 [设计方案](../codex-bar-proposal-20260926.html)。

## 本版变化

- 默认收起的侧栏额度入口，在原位展开成详情卡；套餐、数字、细条和时间环连续过渡，开关动画可随时反向。
- 设置与固定收起按钮共用实测中心轴，主要间距采用 8px 节奏。正常卡片无横纵溢出，不显示滚动条；短窗口的设置内容仍可通过滚轮和键盘访问。
- 四枚工具图标按 16px 重绘；刷新使用原生旋转与淡入淡出交接，保留真实请求状态、限流和失败语义。
- 恢复普通官方入口自动加载逻辑，通过 Windows 包激活保留 MSIX 身份；Helper 启动时已存在的 Codex 会话保持不动。
- Doctor 以真实入口可见为健康条件，保留多窗口汇总和缺失窗口诊断。

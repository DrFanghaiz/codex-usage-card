# v2.3.0 发布验证

2026-10-05。本版仅支持官方 ChatGPT 账户额度，已移除 API 余额卡、外部余额请求和相关 Python 路径。使用 API Key 登录时不推测官方额度；当前外观与技术参数见 [设计方案](../codex-bar-proposal-20260926.html)。

## 本版变化

- 折叠侧栏采用与宿主导航一致的 20px 动态仪表，指针显示剩余额度；多个窗口采用剩余最少者，右侧为 100%。
- 设置页按显示与提醒分组，统一间距、对齐和文字层级；额度页与设置页连续切换，随时可返回、收起或反向。
- 图标模式的卡片保持轮廓并整体轻移、淡出，修复白色方块；淡入途中切设置保留当前透明度和位置。
- 修复通知授权迟到导致开关反弹、旧面板复活和重复入口；保留跨窗口设置同步。
- 严格校验官方额度数字、窗口与套餐类型；请求前检查账户指纹、返回前检查会话代次，保留同账户 429 冷却。
- 修复配置目录消失导致监听失效、CDP 持续响应绕过超时、Python 误判安装状态和重复注入等问题。
- 安装与卸载停止进程前持有句柄、复核路径和创建时间，拒绝 PID 被复用后的其他进程。

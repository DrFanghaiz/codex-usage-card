# v2.3.1 发布验证

2026-10-21。本版修复宿主通过父容器裁剪收起侧栏时，头像上方额度仪表消失的问题，并同步修正自检的可见性判断。

## 本版变化

- 入口挂载计算视口与各级 overflow 裁剪区的交集，不再将保留完整尺寸但完全被裁剪的列表列视为展开状态。
- 观察裁剪祖先的实际尺寸变化，兼容子列尺寸不变、父级宽度动画变化的侧栏收起与展开；始终复用同一个入口。
- doctor 与 Python `card_present()` 同步考虑裁剪、边框、滚动条及缩放，避免报告不可见入口为正常。
- 保留既有仪表指针、动效、额度语义、请求限流、账户隔离与启动链。设计与技术细节已同步到[当前设计方案](../codex-bar-proposal-20260926.html)。

## 原官方快捷方式的验证边界

本机仅修改原官方 `.lnk` 的 Arguments，保留包应用目标，加入 `--remote-debugging-address=127.0.0.1 --remote-debugging-port=0`。一次手动完全退出再打开后，新进程直接获得动态 loopback 端口，Helper 未触发二次重启。没有新增启动脚本。

该结果属于本机已配置的具体快捷方式；本版安装器不会自动修改其他电脑的原官方快捷方式，不承诺所有入口或未来宿主版本都可免重启。

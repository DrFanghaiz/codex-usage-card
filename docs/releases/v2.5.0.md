# v2.5.0 发布验证

2026-10-24。将原位红色额度提醒、官方快捷方式参数自动恢复，以及此前已部署的网络设置与诊断改进一起发布。

## 变化

- 取消独立额度 Toast，在原入口平滑切换为红色提醒。外框、套餐徽标和展开按钮固定；真实已用值与剩余值交叉过渡，不生成中间额度值。动画可打断，提醒当前画面接入共享展开动画；快照保留实际字体与百分号尺寸。每个窗口稳定可见 6 秒，悬停、焦点、隐藏或详情展开时暂停；恢复提醒为中性色，多个窗口顺序展示。
- 现有 Helper 在启动与快捷方式变化时检查缺失的调试参数。保留官方包目标、PIDL、其他参数与元数据；正确入口不重写，冲突或不同目标安全跳过。更新重建后保存新版恢复基线并保留旧备份。安装、维护、回滚和卸载共用互斥锁，父 Helper 身份检查防止卸载后再次补参；失败有界重试。
- 新安装明确保存系统网络设置；升级只迁移一次既有代理选择。提供 `configure_network.ps1`，保存配置时备份并使用 DPAPI 保护代理认证信息。诊断显示脱敏模式、来源、端点与错误；不共享宿主 Electron 网络会话，不新增网络探测，保留旧成功额度、账户隔离和限流链。

更详细的行为和历史实机记录见[原位提醒方案](../codex-bar-proposal-20260926.html#notification-toast)、[快捷方式恢复](../shortcut-repair-20261024.md)、[网络策略](../network-policy-20261022.md)。

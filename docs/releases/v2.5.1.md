# v2.5.1 兼容性修复与发布验证

2026-10-27。修复折叠侧栏残留正亚像素交集时，额度入口未移入导航图标栏的问题。v2.5.0 的原位红色提醒、快捷方式参数自动恢复及网络策略继续保留。

## 实现

- UI、Doctor 与 Python `card_present` 以视口及祖先裁切的交集为准，宽高均至少 1 CSS px 才算可见。保留边框、滚动条、宿主缩放、display:contents 等已有规则。
- 列表挂载还需容纳实测宿主按钮、不可收缩的套餐徽标/箭头、入口间距与 footer 内缩。约 0.009px 或其他过窄残留使用同一个导航栏入口，不增加第二个控件。
- 可见列足够时，footer 根据被裁切的左右空间收窄，继续使用真实头像几何对齐；弹层按实际可见列宽计算边界。避免把仍可使用的窄窗口一律当作折叠状态。
- 持续观察所有列表候选及裁切祖先，包含当前零宽度或不可用的列；列表栏自身的宽度动画可以重新唤醒挂载，无额外轮询。
- 后台 Helper 二进制和启动/请求链未修改；本次仅修 UI 几何判断与诊断探针。

## 验证

所有布局使用隔离合成页面，未连接故障机器或修改真实登录、额度与快捷方式。

| 检查 | 实际结果 |
| --- | --- |
| `node --test tests/native_patch_runtime.cjs` | 最终候选 53/53，0 失败、0 跳过 |
| `python -m pytest -q tests --tb=short`（设置既有 Playwright `NODE_PATH`） | 61/61，0 失败、0 跳过 |
| 版本与摘要更新后复验 `test_native_helper.py / test_page_injector.py / test_doctor.py` | 32/32 |
| `npm run build:check`、语法及 `git diff --check` | 通过，UI 与 Doctor 镜像一致 |
| 实际 ZIP 离线安装 `-SkipTaskRegistration` | 10 个 Skill 文件、6 个运行文件逐字节一致，不注册真实任务或配置快捷方式 |

完整回归曾发现过度保守的挂载判断会破坏窄视口头像对齐，已在实现中修正后重跑通过；保留原对齐断言。另补测不可收缩徽标/箭头占位，避免仅按宿主按钮宽度判断而漏掉极窄列。未通过的中间候选未发布。

新增 UI 场景覆盖 DPR 1 / 1.25 / 1.5 / 2、CSS zoom 0.8 / 1 / 1.25 / 1.5 / 2，以及 0 / 0.009 / 0.5 / 0.999 / 1 / 4px 裁切残留；检查冷启动、点击命中、唯一入口、头像对齐、部分裁切列弹层边界、动画折叠往返、列自身宽度变化、窗口缩窄及观察器静止。另覆盖 Pro/Plus 常态与低额度下 52 / 60 / 80 / 92 / 96 / 180 / 238px 可见列宽的固定按钮可点击性。

诊断探针增加精确数值边界和 216 组真实 DOM 布局：DPR 1 / 1.25 / 2、CSS zoom 1 / 1.25 / 2，横纵方向、视口及祖先裁切，0 / 0.009 / 0.5 / 0.999 / 1 / 1.25px 交集。1px 通过，小于 1px 不通过；不要求成功额度数据或展开弹层。

本轮未在不同物理显示器或故障机器实测；上述 DPR 和 CSS 缩放是浏览器模拟。未来宿主 DOM 结构变化仍需适配，不能外推为所有后续宿主版本完全兼容。Helper 沿用 v2.5.0 已验证产物，仍为 NotSigned。

# v2.6.0 本机用量统计与版本更新提醒

2026-10-28。新增原位本机统计、每日用量图表与 API 等值，完善统计页动画和自绘日历，加入低打扰版本更新提醒。继续保留 v2.5.1 的缩放／亚像素兼容、官方快捷方式参数维护和官方额度契约。

## 功能与边界

- 从刷新旁的统计按钮打开今日、本周（本地周一至今）和含首尾的自选日期。点击日期柱查看当天 token 和 API 等值，不重复请求或扫描；统计与官方额度独立。
- 只读本机 sessions／archived_sessions，增量读取、累计差分、复制／分叉去重，可验证的子代理启动继承不算新增消耗；统计不完整按所选日期解释，不把未知数据当零。日志可能包含历史账户或导入记录，不能据此证明物理设备来源或账户全量。
- 周额度是基于 ModelDial Pro 200 新额度样本的参考估算，不是官方固定 token 上限，未逐账号校准；不再次对新额度样本减半。API 等值按已记录输入／缓存读取／写入／输出与 2026-10-27 核对的 Standard 短上下文价格估算，未定写入时长给范围，未计价模型单独说明；不是订阅实付账单，不含长上下文、加速、地区或工具附加费用。
- 统计页使用宿主协调的暖赭／鼠尾草绿／灰蓝图谱，数字保留精确 title／读屏值。日期选中、柱形、范围切换与明细采用 140–240ms 可打断动效；固定卡片底边与收起按钮，修复读取状态额外撑高 32px 和隐藏表单错误 FLIP 起点。
- 日期输入使用同主题自绘月历，支持手输、月份切换、方向键、Home／End、PageUp／PageDown、今天及 Escape；严格检查真实日期、闰日、起止顺序与未来日期。
- 公开 GitHub 稳定版检查不携带账号凭据，复用现有网络设置而不污染官方诊断。检查前持久化尝试时间，成功／失败均 24 小时内复用缓存，独立任务不阻塞额度请求。新版只显示静态设置圆点和版本行，真正可见才确认已读，跨窗口最高已读版本只升不降。

## 固定升级方式

从对应 Release 获取固定 tag 安装命令，安装器下载同版本 Skill ZIP 并验证固定 SHA-256，再沿用现有备份、配置保留、任务身份校验、快捷方式维护与失败回滚。提醒只打开说明页，不自动执行代码。

```powershell
$installer = Join-Path $env:TEMP 'install-codex-usage-card.ps1'; Invoke-WebRequest 'https://raw.githubusercontent.com/DrFanghaiz/codex-usage-card/v2.6.0/install.ps1' -OutFile $installer; Unblock-File -LiteralPath $installer; & $installer
```

自定义安装目录升级时，在执行安装器时继续传入原 `-InstallRoot`；不要把已有工作区部署切换到默认目录。

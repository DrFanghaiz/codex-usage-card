# v2.6.1 统计页、动效与可靠性修订

2026-10-28。整合 v2.6.0 之后的统计页 UI 改进、动画与性能优化，以及本轮确认的 Bug 修复。官方额度显示、请求限流、账户隔离、默认收起和单一入口契约继续保留。

## 改动

- 统计页分为“用量／每日／详情”，按当前内容原位展开。首载有骨架，刷新保留原值与日期，失败可就地重试；隐藏状态不再占用底部空间。
- 模型明细按本机区间 token 排序，用暖棕、鼠尾草绿和蓝灰细条展示占比，统一名称、数字和轨道边界。完整计数保留；参考周总量、API 等值来源和口径说明分组呈现。
- 首次打开前完成骨架测量；打开途中回包重新设定动效目标；内部高度变化与返回／收起交接时保留当前画面。重复点击当前页不再重建图表或播放无效动画。
- 侧栏宽度变化后重排每日图表 5／7 列、选中底色和键盘焦点，保留日期、不新增查询；图表批量构建和测量，减少重复布局。
- 修复明确不同会话同时间同累计计数被误去重的漏算，保留归档副本、明确父历史和子任务启动继承规则。超大未完成 token 尾行如实标记不完整；未变化 EOF 日志跳过重复解析流与缓冲区分配。
- 修复 Windows PowerShell 5.1 对多调试目标的解析误报；同步诊断镜像，并修正过期的启动测试夹具边界。

## 测量与验证

完整自检见[本轮审计记录](../audit-20261028.md)。同一合成场景中，1000 个未变化日志的 5 轮交错暖查询中位耗时从 141.25ms 降至 83.25ms；每次省去 1000 个 64KiB 输入缓冲区分配。7 根柱子翻页的布局计算从 20 次降至 8 次。

实机 8 组短时前台采样中，未出现超过 33.4ms 的 RAF 帧间隔或超过 50ms 的长任务，结束后无活动动画或临时图层。这不代表所有硬件与长期运行条件下的 FPS 保证。

## 安装与升级

在 PowerShell 7 中运行固定版本安装器：

```powershell
$installer = Join-Path $env:TEMP 'install-codex-usage-card.ps1'; Invoke-WebRequest 'https://raw.githubusercontent.com/DrFanghaiz/codex-usage-card/v2.6.1/install.ps1' -OutFile $installer; Unblock-File -LiteralPath $installer; & $installer
```

自定义安装目录的用户继续传入原 `-InstallRoot`。安装器下载同版本 ZIP、校验固定 SHA-256 后沿用现有配置保留、备份回滚和官方快捷方式维护。更新提醒只打开说明，不自动执行升级代码。

# v2.6.2 区间查询与旧 Pro 20x 双口径估算

2026-10-30。整合任意区间查询、账号采样持久化、旧 Pro 20x 双口径估算与快捷时长切换。统计仍在列表侧栏原位展开，官方额度、限流、账户隔离及默认收起保持原有契约。

## 改动

- 区间页分别提供起止日期、自绘日历、秒级时间与独立滑轨。滑轨下方新增 5min／10min／30min／1h 四段快捷切换，填写截至点击时刻的最近区间；下一行保留当前时长和右对齐的查询按钮。
- 所有输入与快捷选择只修改草稿，点击“查询”才提交；读取保留原结果及实际区间，相同在途请求不重复排队。修复切回日期页或切换参考套餐时隐式提交未查询区间草稿的问题，其他请求复用上次已提交区间。
- Pro $200 选项明确对应旧 20x，使用 ModelDial 明确的周 Token 和周 API 等值字段，不把截图月值当周值。分别按模型归一化后相加，展示 Token／API 两口径的最小至最大参考范围，详情保留各自读数；不平均、不叠加两者。
- 每日匿名检查保留持久 24 小时尝试间隔；旧档成功缓存与现代档检查状态分离。没有已确认旧档缓存时，明确显示已核实的旧档参考快照；失败不退回较低的新 Pro 200 分母。
- 账号官方成功采样按匿名账号摘要在本机持久保存，取消四小时裁剪，重启恢复；只读取所选日期与必要边界日。采样不足、间断、跨重置、损坏及读写失败继续如实展示，不插值、不增加官方请求。升级和卸载保留历史。
- 统计宽度限制在列表列内，精简重复说明，统一数字、对齐与语义色；切页、选中及布局过渡可打断，保留键盘、高对比度和减少动态效果。

实现与边界见[区间查询](../interval-query-20261030.md)、[旧 20x 与双口径](../legacy-pro20x-20261030.md)、[账号采样历史](../account-history-20261029.md)和[统计排版复核](../stats-layout-audit-20261030.md)。

## 安装与升级

在 PowerShell 7 运行固定版本安装器：

```powershell
$installer = Join-Path $env:TEMP 'install-codex-usage-card.ps1'; Invoke-WebRequest 'https://raw.githubusercontent.com/DrFanghaiz/codex-usage-card/v2.6.2/install.ps1' -OutFile $installer; Unblock-File -LiteralPath $installer; & $installer
```

自定义安装目录继续传原 `-InstallRoot`。安装器下载同版本 Skill ZIP 并校验固定 SHA-256，沿用配置保留、备份回滚和官方快捷方式参数维护；不增加启动脚本、不改变官方包应用目标。更新提醒只打开说明，不自动执行升级。

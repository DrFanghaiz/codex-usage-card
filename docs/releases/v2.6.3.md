2026-11-03。整合 Helper 入口恢复的诊断改进、官方请求失败冷却和 ModelDial 参考同步改版兼容。官方额度与第三方估算来源保持独立。

## 改动

- 本机停止的 Helper 已恢复，Codex 26.1027.6604 的入口、调试连接和官方请求验证正常，客户端根进程保持不变。后台致命托管异常补充类型／HRESULT 脱敏记录，沿用现有 startup.log，不记录原始异常消息。此前进程停止原因仍未确认，不能宣称已修复所有意外退出。
- 官方请求的所有失败由 Helper 统一冷却至少 60 秒，手动和多窗口请求不能绕过。连续临时失败按 1／2／4／8／15 分钟退避，成功或凭证修复清除普通退避；同账号 429／503 服务端冷却不被凭证改写绕过。
- 失败回复携带绝对 UTC 截止和剩余秒数，缓存回放不重新延长等待。保留上次成功额度和时间，沿用原刷新按钮反馈，不增加状态行、连接探针或轮询。
- 修复 Helper 升级后页面仍显示旧已安装版本的问题：注入时更新当前版本，保留已检查的最新版本、时间和冷却，不增加 GitHub 请求。
- ModelDial 兼容新旧 Token 单位文案、Pro 100／5x ID、更大的订阅数据模块及来源明示的旧 20x → Pro 200 迁移。只读取明确周字段，不把月值当周值，不自行乘倍数生成替代基准。
- 区分仅含套餐 ID 的元数据模块和真正额度数据；严格验证迁移证据、套餐及同模型投影关系。相同 canonical literal 可去重，冲突数据仍失败。脚本不执行，同站候选最多八个，HTML／脚本读取有界。
- 当前套餐与旧档独立更新，各自保留真实成功时间。完整成功后每 24 小时复核，失败按 1／3／6 小时退避并持久保存，重启不提前重试。失败链接明确显示“ModelDial · 更新失败”，悬停显示成功／尝试／下次检查时间。

实现、来源及边界见[官方请求与入口诊断](../sync-repair-20261103.md)和[ModelDial 同步修复](../modeldial-sync-20261103.md)。

## 安装与升级

在 PowerShell 7 执行固定版本安装器：

```powershell
$installer = Join-Path $env:TEMP 'install-codex-usage-card.ps1'; Invoke-WebRequest 'https://raw.githubusercontent.com/DrFanghaiz/codex-usage-card/v2.6.3/install.ps1' -OutFile $installer; Unblock-File -LiteralPath $installer; & $installer
```

自定义安装目录继续传原 `-InstallRoot`。安装器下载同版本 ZIP 并校验固定 SHA-256，保留原配置、账号采样历史和 ModelDial 缓存，沿用备份回滚及官方快捷方式参数维护；不增加启动脚本，不改变原包应用目标。

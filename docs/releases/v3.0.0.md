# v3.0.0 逐条本机额度估算

在 Codex 回复的用时旁展示本机周额度估算，按根轮次归集主任务和子任务，复用本机日志去重；缺少日志或基准时明确提示。统计页及逐条显示支持按 API 等值进行间接估算，范围不是官方实际扣量，也不保证真实值落在其中。根据用户确认的口径，自动审核保留 token 统计但不占周额度；未知 API 价格不按零伪造。

# v3.0.1 消息摘要与性能修复

“上 N 条消息”和“用时”现在都在原位显示该轮次的本机额度估算，使用相同轮次标识，不将 N 条消息当作 N 个轮次相加。日志不完整或无匹配记录时保留明确提示；估算不是官方实际扣量。

滚动时不再反复改写未变化的额度标签。主轮次中止后，Helper 会等待仍在运行的子任务结束，再停止重复查询；对于同一操作的归档副本，只有可确认更晚的结束事件才会覆盖旧的活动记录，时间缺失或冲突时保守保留不完整状态。


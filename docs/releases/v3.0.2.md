# v3.0.2 跨周期额度统计

查询区间跨越周额度重置时，统计页按官方成功采样的重置时间分段，累计各段已采样的额度变化；“采样 N 段”可展开查看每段时间和百分点，支持键盘操作。多周期累计可超过 100 百分点。

重置前后、单点周期及采样缺口不会补算，结果包含其他设备，不能视为完整实际消耗或严格下界。若重置时间提前变化且计数回落，界面只展示各段采样，不累计存在歧义的总值；同周期计数校正仍标记为不可用。账号隔离及官方请求频率保持不变。

安装包 `codex-usage-card.skill.zip` SHA-256：`73C13B486C4A6C5F9A8D686442E32787EF1EEB579DE34DBEB211D0C5CD27A277`。

```powershell
$installer = Join-Path $env:TEMP 'install-codex-usage-card.ps1'; Invoke-WebRequest 'https://raw.githubusercontent.com/DrFanghaiz/codex-usage-card/v3.0.2/install.ps1' -OutFile $installer; Unblock-File -LiteralPath $installer; & $installer
```

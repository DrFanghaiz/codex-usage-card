# v3.1.0 快捷查询与浮层改进

- 新增「近 1 小时」快捷查询。点击结果日期可编辑起止时间，点「应用」后才提交自选区间。
- 显示本机日志记录的周额度和观测时间，并标注「账号未核验」。账号采样变化继续单独显示。
- 低额度提醒在侧栏原位置增加感叹号，悬停或聚焦时显示余量。提醒开关移至设置首屏，周图补齐指标标签，日期控件加大点击区。
- 对齐逐条估算与宿主用时文字的字号、基线和数字字形。兼容 Codex 动态分配的本地调试端口。

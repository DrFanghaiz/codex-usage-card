# v3.2.0 安装、自检与对话用量

- 从原有 Codex 快捷方式启动。新版安装器不再创建独立的「Codex（额度卡）」桌面入口。升级成功后，已确认属于额度卡的旧快捷方式会移入安装备份。
- Windows 自带的 PowerShell 5.1 和 PowerShell 7 均可用于安装和卡内自检。「复制诊断」包含后台版本、实际加载的界面版本及匹配结果。
- ModelDial 提供同套餐的 6.2 Sol 或 Astra 周数据时，优先使用其 Token 和 API 等值参考。旧 Pro 20x 使用自己可核验的周参考，缺少新模型数据时按已有模型间接估算。[ModelDial 周用量](https://modeldial.com/subscriptions?period=week&view=insights)
- 统计浮层提供「本对话累计」，展开时读取当前对话可归属的本机用量。包含可确认的子任务，合并重复记录，并标注不完整或无法归属的情况。

安装包 `codex-usage-card.skill.zip` 的 SHA-256 为 `7826DDF9D52A46DE2A879BE44A057A1360746403481ECEA18529015112071861`。

在 Windows PowerShell 5.1 或 PowerShell 7 中运行以下命令。

```powershell
$installer = Join-Path $env:TEMP 'install-codex-usage-card.ps1'; Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/DrFanghaiz/codex-usage-card/v3.2.0/install.ps1' -OutFile $installer; Unblock-File -LiteralPath $installer; & $installer
```

自定义安装目录继续传入原来的 `-InstallRoot`。

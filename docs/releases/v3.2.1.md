# v3.2.1 对话累计用量

- 「累计用量」移到对话标题右侧。点击查询本机累计用量，标题旁保留估算百分比，浮层显示 Token、API 等值和数据完整性。切换对话时清除旧读数。
- 累计查询使用正文的轮次标记核对归属，即使当前视野内没有「用时」按钮，也可以查询。日志覆盖不足时继续显示「不完整」。

安装包 `codex-usage-card.skill.zip` 的 SHA-256 为 `40788E7A5464456BCA00639B1B46A48FE3F98FEED699B244DE76866C97765656`。

在 Windows PowerShell 5.1 或 PowerShell 7 中运行以下命令。

```powershell
$installer = Join-Path $env:TEMP 'install-codex-usage-card.ps1'; Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/DrFanghaiz/codex-usage-card/v3.2.1/install.ps1' -OutFile $installer; Unblock-File -LiteralPath $installer; & $installer
```

自定义安装目录继续传入原来的 `-InstallRoot`。Helper 尚未签名。

# v3.2.2 用量浮层排版

- 对话标题右侧的「累计用量」优先显示本机额度估算。Token 和 API 等值分行显示，数值统一右对齐，覆盖不完整时仍有提示。
- 账号变化独占一行，标签靠左、百分点靠右，改用中性色。部分采样仍直接标明，悬停可查看「含其他设备」。
- 统计、设置和累计用量浮层统一使用 Codex 原生菜单的背景色。

安装包 `codex-usage-card.skill.zip` 的 SHA-256 为 `B2917FE31403D54988914C20DFC541BF82A8D1E85AB48653596E2BAAE4D0B2F4`。

在 Windows PowerShell 5.1 或 PowerShell 7 中运行以下命令。

```powershell
$installer = Join-Path $env:TEMP 'install-codex-usage-card.ps1'; Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/DrFanghaiz/codex-usage-card/v3.2.2/install.ps1' -OutFile $installer; Unblock-File -LiteralPath $installer; & $installer
```

自定义安装目录继续传入原来的 `-InstallRoot`。Helper 尚未签名。

# v3.2.3 跨周期账号变化

- 「账号变化」将重置前后已采到的百分点变化合计为一行，并标注「部分」。跨越多个周期时，合计可以超过 100 百分点。
- 过期样本只形成采样缺口，其余可核对的变化仍计入合计。缺少可计算的样本时显示「采样不足」。

安装包 `codex-usage-card.skill.zip` 的 SHA-256 为 `D816B37218C4E7E15A1F659C437EE3DCF9708E567F722078CDC0AFC2CDC23179`。

在 Windows PowerShell 5.1 或 PowerShell 7 中运行以下命令。

```powershell
$installer = Join-Path $env:TEMP 'install-codex-usage-card.ps1'; Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/DrFanghaiz/codex-usage-card/v3.2.3/install.ps1' -OutFile $installer; Unblock-File -LiteralPath $installer; & $installer
```

自定义安装目录继续传入原来的 `-InstallRoot`。Helper 尚未签名。

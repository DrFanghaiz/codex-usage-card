# 设置页布局与连续过渡 · 2026-09-29

本次修改已部署到当前实机，属于 v2.2.0 之后的本地工作版本，未创建新的公开 Release。[设计方案](codex-bar-proposal-20260926.html)已同步布局、技术参数与实机截图。

## 改了什么

- **8px 间距节奏**：行内间距 8px、分组留白 16px；设置行最小高 32px，工具与返回按钮点击区域至少高 24px。
- **统一对齐**：标题、分组名、设置标签与底部诊断操作共用左边界；开关和阈值输入共用右边界；右上返回图标与固定收起按钮共用中心轴。
- **信息层级**：14px/600 标题，12px 主设置，11px 分组名、阈值与诊断操作。按“显示 / 提醒”分组，百分号放入阈值输入框；原生开关、输入校验与无障碍语义保留。
- **连续切页**：额度内容淡出、设置内容淡入，配合 8px 横向位移；卡片从固定底边伸展，文字仅平移、不随整卡缩放。返回沿相反方向过渡。

## 根因与实现

此前 `openSettings` 先隐藏旧页，`animatePane` 仅做 160ms 裁切和新页淡入，缺少旧内容退场。中途返回/收起又先清理动画、再测量完整终态，造成可见高度跳变。隔离复现曾测得返回时约 230→343px、收起时约 248→343px。当前观察器没有取消该动画，未为此改变观察逻辑。

现在额度页和设置页在同一个原生 popover 内保留至过渡结束；非目标页使用 `inert` 和 `aria-hidden`，不接收输入或重复读屏。复用已有 spring 预采样与原生 WAAPI 播放器 `playSpring`，未增加依赖。物理参数保持 stiffness=420、damping=42、mass=1、restDelta=.001、restSpeed=.01，按 1000/120ms 采样关键帧；这不是固定时长，也不代表达到 120fps。

返回、收起、重新打开都先读取当前原生动画时钟对应的显示状态，继承可见边缘的速度，再重定向目标。弹层只在起点测量并预留两态边界，过程中使用原生 clip-path、transform 和 opacity；不逐帧写 height/top 或拉伸文字。收起时箭头仍绘制，列表列中由原入口承接原位置的下一次真实点击；侧栏折叠模式退出期间也保留 700ms 原生 display/overlay 绘制窗口，避免原来的 180ms 提前截断 spring。

隐藏、减少动态效果、账户重置、重注入和真实几何变化沿用即时清理。无效阈值仍可返回；短窗口不显示滚动条，但保留滚轮与键盘访问。请求、限流、数据含义与账户隔离未改动。

# 独立 Toast 历史验收（2026-10-22）

> 2026-10-23 设计状态：用户已批准取消独立 Toast，采用额度入口原位红色提醒。当前生产集成与实机热部署已完成（50 项完整回归、最终 11 项相关复验、实机 Active）；下列实现、测试数、哈希和部署记录只属于 2026-10-22 历史版本，不作为新方案的验收结论。当前规范见 [方案文件的原位提醒章节](codex-bar-proposal-20260926.html#notification-toast)。

新方案沿用既有阈值、每周期与跨应用窗口去重、账户隔离和可选系统通知。每个额度窗口的提醒依次显示，稳定可见 6 秒；悬停、聚焦、页面隐藏、入口不可见和详情展开时暂停。低额度使用红色层，恢复额度使用中性层；原位动画可反向，开卡前正确交接视觉层，保持入口点击与详情动画可用。


历史版本当时已热更新 Codex 页面，未发布 GitHub。范围仅为低额度及恢复提醒的显示与交互，保持原阈值、跨窗口去重、账户隔离和系统通知权限链。

## 实现

- 靠近额度入口显示，优先在入口或展开卡片上方，空间不足时尝试侧面；通过宿主 `[data-composer-body]` 的真实矩形避让输入区。均无可用空间时隐藏并暂停计时，恢复空间后继续。
- 根据用户反馈移除大标题、警告图标及厚留白，改成约 42px 高的轻薄提示条。使用宿主 surface / foreground、小圆角、94% 表面色与 8px 模糊、浅边框；阴影减轻为一层。内边距与列间距均为 8px，正文 13px，数字 600 字重；关闭按钮保留 24px 点击区域。高对比环境有实体表面回退。
- 单行显示「本周剩余 15%」，仅数字使用警示色；恢复显示「本周已恢复 100%」。多窗口逐行说明，系统通知保持原完整文本。
- 累计可见 6 秒退场，悬停、焦点、隐藏页面或空间不足时暂停。关闭支持鼠标、键盘及 Escape；新消息替换同一条提醒，重置计时。关闭与新消息不会等待旧动画。
- 状态文字使用 `role=status`，不抢焦点。仅动画 transform / opacity；减少动态效果时即时完成。退出、会话重置、重新注入均释放计时器、观察器和监听器。
- 卡片展开时将手动 Toast 挂在该原生 popover 内，防止关闭 Toast 被识别为外部点击而误关额度卡；卡片收起后回到页面根节点。

# 本机用量界面：信息逐项审查

2026-11-04。目标是让用户快速看清本机消耗、构成和所查区间，官方账号总览继续由原生组件负责。本轮检查了实机的用量、单日、多日、详情、参考展开、区间和设置七种状态，保留原位浮层、数据算法和请求链路。

## 展示取舍

| 信息／控件 | 决定与形式 | 原因 |
| --- | --- | --- |
| 本机用量标题 | 保留一次 | 明确数据来自本机日志，不能与账号全量混淆 |
| 刷新、设置、关闭 | 保留图标，保留可访问标签及悬停说明 | 三者作用不同，无需占用文字按钮空间 |
| 今日／本周／自选日期 | 保留分段选择 | 决定统计范围，与下方内容页不是同一维度 |
| 用量／构成或每日／详情／区间 | 保留内容页 | 单日看构成，多日看趋势；查询能力不删减 |
| 结果日期／区间 | 保留实际结果归属 | 日期输入可能是未提交草稿，不能拿它冒充现有结果范围 |
| 总 token | 首页主数字 | 回答本机一共消耗多少，精确数放悬停及无障碍文本 |
| API 等值 | 首页次主数字 | 有助于比较用量价值；显示估算符号，部分计价直接标一次“部分” |
| 输入／输出 | 两个对齐的次级数字 | 是总量最有用的基本拆分 |
| 非缓存输入 | 从首页平铺中移出 | 属于输入的派生量；在构成页及缓存条提示中查看 |
| 缓存绝对量 | 从首页平铺中移出 | 与输入及命中率重复；精确数保留在构成页、悬停和无障碍文本 |
| 缓存命中率 | 一个百分比＋细条 | 解释输入结构；分母是输入 token，不能与总 token 构成混用 |
| 单日独立柱子 | 改为一条三段构成条＋三行分类数 | 没有时间比较对象的单柱只重复总数；构成条表达输入、缓存、输出的关系 |
| 单日总量／API重复数字 | 从构成页移除 | 首页已展示；构成页只回答消耗由什么构成 |
| 多日堆叠柱图 | 保留 | 表达每日趋势，点击或键盘选择一天后显示当日 token 和 API 等值 |
| 图表图例 | 保留语义色点与短标签 | 颜色承担非缓存、缓存、输出三种信息，不能仅靠颜色辨认 |
| 图表尺度上限 | 多日保留，单日移除 | 多日需要解释柱高；单日不再有相同比较尺度 |
| 翻页箭头 | 有前后页时才显示 | 无法翻页的两个灰箭头没有操作价值 |
| 模型名称／绝对 token | 默认直接展开 | 是详情页最有用的实际信息，避免进入详情还只有折叠目录 |
| 模型横条／百分比 | 横条保留；百分比进提示及无障碍属性 | 相对大小有助比较，不再同时平铺数字、百分比和横条三种读法 |
| 模型数量角标 | 移除 | 与已经展示的列表相比价值低 |
| 周额度双口径估算 | 合并到“口径与来源”内的可选折叠项 | 不与本机实数争主位；无可比模型或未选套餐时不显示无效的横线表 |
| 套餐选择／基准／ModelDial来源 | 与估算放在同一入口 | 不再让用户往返两个折叠项；档位由选择框表示，不再重复写在旁边标题 |
| 无周参考／无 API 价格 | 分别放到对应来源位置 | 不再混成“未折算／计价”，也不让用户误以为 token 漏算 |
| API 价格来源与日期 | 保留一个链接 | 便于核对价格口径，删除重复的 API／USD 小标题 |
| 口径长说明 | 缩短后集中折叠 | 保留非账单、非官方扣量、缓存写入区间、本机日志与采样边界 |
| 区间本机 token／API 等值 | 保留 | 对应用户提交的任意时段，未增加官方请求 |
| 账号周额度变化 | 保留独立数值 | 是账号成功采样的百分点差，含其他设备，不能作为本机精确扣量 |
| “完整覆盖”成功文字 | 移除常驻显示 | 正常状态无需不断解释；有缺口、跨重置或错误时才突出提示 |
| 部分覆盖／采样间断／真实端点 | 保留明确文字及端点 | 分别说明边界覆盖和内部连续性，不能只留一个没有解释的感叹号 |
| 读取中 | 保留标题状态、刷新动效和首屏骨架 | 删除骨架旁重复的读取文字，保留屏幕阅读器状态 |
| 首次读取失败 | 一处不可用提示＋重试 | 不再同时出现两段同义不可用说明 |
| 已有结果时读取失败 | 保留旧结果并提示失败 | 用户需要知道当前仍是上次结果，不能静默吞掉失败 |
| 统计不完整 | 短状态；具体原因与数量按需查看 | 不在页脚、模型列表和详情反复抄写同一组原因 |
| 12 小时制开关 | 从新设置页移除 | 新区间输入固定为 24 小时，此开关主要服务旧额度卡和诊断格式；保留原偏好存储 |
| 低额度／恢复提醒 | 保留两个独立开关 | 作用不同；提醒仍可选，不改变用户已有选择 |
| 阈值／系统通知 | 按上级开关显示 | 未启用低额度提醒时隐藏阈值；两种提醒都关闭时隐藏系统通知 |
| 自检／复制诊断 | 自检保留，复制仅在有诊断结果时出现 | 没有可复制内容时，不展示空操作 |
| 当前版本／版本说明 | 保留一行 | 一个是安装状态，一个是查看发布说明的操作，不属于重复指标 |

## 同时修复的语义问题

区间页原先会把“当前模型没有 ModelDial 周参考”也标成“部分统计”。本机 token 已经来自日志计数，因此是否统计不完整现在仅由日志覆盖状态决定；参考覆盖不足只影响可选估算，不影响已计入的 token。

无基准、无可比模型及空记录不再显示“未折算＋Token—＋API—”的空表。真实记录的零消耗仍可以显示真实零值；缺失、不可用和未计价继续明确区分。未配置 Pro 档位不再把全部 token 罗列成“无周参考”告警。

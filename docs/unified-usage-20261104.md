# 统一用量主页面

2026-11-04，v2.7.0 发布界面。Helper 与公开安装器版本及校验值随发布同步。

## 阅读顺序

入口保持在官方额度图标上方，点击后只有一张主页面，默认收起。本轮按[双刻度实现指令](codex-implementation-brief-20261104.md)与[目标界面](local-usage-dual-scale-20261104.html)采用 Sand 浅深实底、细外边及同心圆角；字体和入口几何关系沿用宿主，不再沿用旧版半透明材质。

本页面采用 Impeccable **Operate** 模式：打开、选择时间、读取结果，再按需展开细节或设置；持续产品事实见 [PRODUCT.md](../PRODUCT.md)，实际视觉令牌见 [DESIGN.md](../DESIGN.md)。

宽度优先读取官方按钮 `aria-controls` 关联、`aria-labelledby` 匹配且可见的真实菜单，将可见宽按按钮缩放换算为 CSS 宽并缓存。首次官方菜单尚未出现时仍用当前宿主 `--spacing × 65`；当前宿主参考值为 260 CSS px，不声称首次就能读取不存在的菜单矩形。

1. 唯一时间选择：今日／本周／自选。
2. 本机额度估算范围与账号额度变化上下分行，作为主要读数；每行标签在左、对应数值在右，两个数值共用右边界，不再显示静态记号。
3. 本机总 token 与 API 等值作为次要读数。
4. 多日范围显示每日堆叠柱图；本周固定七格，无记录以虚线短桩区分，未来日期为空位且不是按钮。点击日期只更新图中的当日明细，主读数保持整个已查询范围。
5. “消耗构成”“按模型查看”默认折叠。构成包含三段横条、非缓存／缓存／输出计数与输入缓存命中率；两种比例的分母分别为总 token 和输入 token。

删除旧的用量／构成／详情／区间页签以及独立日期表单，不再保留两套查询范围。构成折叠标题不重复总 token。参考套餐、双口径拆分、ModelDial 来源、价格与口径说明集中到设置中的“口径与来源”。

## 时间编辑

今日从本地 00:00 至查询时刻，本周从本地周一 00:00 至查询时刻。刷新这两个预设时更新结束时刻；自选保留已提交的绝对端点。

点击“自选”在同一浮层内展开编辑，开始／结束纵向排列。保留自绘日历和秒级时间、5min／10min／30min／1h 快捷时长；两条独立滑轨收进“精细调整”。所有编辑均为草稿，点击“应用”才提交并收起编辑器。再次点击“自选”可收起编辑器，不提交草稿。

读取新范围期间保留上次成功结果和其真实范围；过期请求及与当前精确端点不一致的响应不能覆盖结果。读取失败保留旧结果；首次失败显示不可用及重试。已有结果时刷新在区间状态行显示转圈，旧数字及原结果时间保持不动；首屏有骨架。

## 四项读数的含义

有专属周参考的模型按相同模型集合分别计算 Token 和 API 比例，显示最小至最大参考范围，不平均、不将两种口径叠加，也不宣称真实扣量一定在范围内。无参考套餐时主读数提供“选择参考套餐”入口；无可比基准、无记录和部分模型明确区分。较长范围按上下界分组换行，不缩小主数字来容纳并排读数。

2026-11-05 补充：缺少专属周参考但有 API 价格的模型，可用 Astra 和 Sol 两个周 API 等值参考间接换算。先按该模型输入、缓存及输出价格计算 API 等值，再分别除以两个参考得到范围；直接参考模型仍沿用双口径，其结果与其他模型的间接范围相加。界面标明“间接估算”；没有价格、缺少任一参照或日志不完整时保留未覆盖提示。这个范围基于不同模型的 API 等值可粗略比较的假设，并非官方权重或可信区间。

39 项界面回归通过，覆盖间接换算、直接与间接模型混合、无价格模型和参照缺失。实机热加载后，指定历史回复显示“间接估算”和“不完整”，与宿主用时标签对齐；Helper 自检为 Active，原 Codex 进程保留。

同日后续修正：根据用户确认的官方口径，`codex-auto-review` 不占周额度；保留其 token 记录，但周额度估算按零计入，不再因此标记模型覆盖不完整。其他未知模型仍不推断为零。由于没有该项的独立 API 报价，API 等值仍显示未计价或部分计价，不用订阅额度规则代替 API 价格。

相关 6 项界面回归及构建检查通过；热部署后，指定历史回复显示间接估算且不再因自动审核标记不完整，入口自检为 Active。未重新运行完整界面套件或关闭 Codex 冷启动。

账号变化来自所选范围内的官方成功采样，单位是周额度百分点，包含其他设备。不把它叫作本机实际扣量，也不将它与本机估算的差额归因给其他机器。缺少两点时不可用；部分覆盖展示真实采样端点；采样间断、跨重置、计数校正和历史存储问题保留明确提示，不能填零。

总 token、API 等值、模型、构成和日柱都使用同一个精确 `(start,end]` 区间。API 等值仍标估算或部分计价，不代表实付费用。

## 数据与性能

### 逐条轮次估算（2026-11-05）

聊天中原生“用时”右侧显示对应轮次的本机额度估算，沿用宿主字体、字号和颜色。估算使用与统计页相同的 Token／API 双口径及当前选择的参考套餐，既不是官方实际扣量，也不保证真实值落在范围内。无记录或缺少基准时明确显示不可用原因；日志、模型或参考不完整时标记“不完整”，运行中的轮次标记“进行中”。

Helper 按根轮次归集主任务与子任务，复用本机日志既有的历史复制和用量去重；另一类用量记录仅用于核对覆盖，不重复计数。只为视口附近的轮次查询，索引复用已有缓存，账号或参考套餐变化时丢弃旧回包；不增加官方额度请求。实际可归属范围由本机保留的日志决定，其他设备的用量不包含在内。

2026-11-06 修订：官方“上 N 条消息”和“用时”是同一轮次摘要的替代显示，均使用该轮次的原始标识查询；不把 N 当作跨轮次合计。中英文摘要、动态文字变化和无记录状态均有回归。滚动时仅在标签内容或样式变化时写入 DOM，原生按钮的样式集中读取；根轮次已中止且可确认没有活动子任务时标记不完整并停止重复查询。复制日志按同线程、同操作的时间合并状态；时间缺失或相同而状态冲突时保持不完整，避免误认已结束。历史日志的尾部校验仍保留，避免同长度文件改写后误用缓存。

该修订已在本机热部署。此前完整界面回归 41 项通过，最后一轮局部调整后相关 6 项复测通过；本机实际用时行显示、对齐与字体正常，三次无变化滚动未触发标签 DOM 更新。用户提供的“上 89 条消息”来自另一台机器，尚未在那里实机验证。

本轮新增轮次归属／子任务／去重／缺失数据回归通过，原有 97 组本机统计和 30 组 Helper 回归通过；界面全量 37 项通过，最终构建的逐轮回归另行通过。实机热部署后，Helper 自检为 Active、单实例且无窗口；真实历史轮次检查了缺少基准与不完整状态以及标签对齐。50 个轮次查询在当前本机日志上冷索引约 5.2 秒、热查询约 73 毫秒，仅代表本次测试。未检查完整冷启动或其他宿主版本。

### 参考套餐按账号保存（2026-11-05）

Helper 在本机按账号保存用户明确选择的参考套餐，并在新会话初始化时恢复。账户指纹留在 Helper 中，页面只接收套餐值；切换账号时读取对应账号的选择，无选择或记录损坏时保持未选择。写入失败时设置页提示重新选择，保存不改变官方套餐或额度，也不增加官方请求。旧版临时会话选择无法安全归属于具体账号，升级后需首次重新选择一次。

合成回归验证两个账号互不覆盖、跨进程恢复、清空和损坏记录处理；界面 38 项及 Helper 30 组回归通过。实机已选择 Pro 200 · 20x，随后仅重启 Helper：初始化值、统计查询和设置选择均恢复为该套餐，原 Codex 进程保留，自检为 Active／单实例／无窗口。未切换真实账号或完整冷启动 Codex。

Helper 的 `interval.local` 增加本地日期 `start/end` 及 `daily`；保留已有 `models/eventCount/partial/issues/hasLogs`。使用同一批去重后记录，在原有精确区间过滤中归日，不为柱图再次扫描日志。日桶各模型之和必须等于区间总量，跨午夜的第一天和最后一天也只计实际选中的部分。

外层整日汇总继续保留以兼容旧界面，新主页面不使用它冒充精确区间结果。账号采样、限流、账户隔离、持久历史和 ModelDial 同步策略沿用现有链路，不增加官方请求。

# 统一用量主页面

2026-11-04，v2.7.0 发布界面。Helper 与公开安装器版本及校验值随发布同步。

## 阅读顺序

入口保持在官方额度图标上方，点击后只有一张主页面，默认收起。本轮按[双刻度实现指令](codex-implementation-brief-20261104.md)与[目标界面](local-usage-dual-scale-20261104.html)采用 Sand 浅深实底、细外边及同心圆角；字体和入口几何关系沿用宿主，不再沿用旧版半透明材质。

本页面采用 Impeccable **Operate** 模式：打开、选择时间、读取结果，再按需展开细节或设置；持续产品事实见 [PRODUCT.md](../PRODUCT.md)，实际视觉令牌见 [DESIGN.md](../DESIGN.md)。

宽度优先读取官方按钮 `aria-controls` 关联、`aria-labelledby` 匹配且可见的真实菜单，将可见宽按按钮缩放换算为 CSS 宽并缓存。首次官方菜单尚未出现时仍用当前宿主 `--spacing × 65`；当前宿主参考值为 260 CSS px，不声称首次就能读取不存在的菜单矩形。

1. 唯一时间选择：今日／本周／自选。
2. 本机额度估算范围与账号额度变化上下分行，作为主要读数；每行标签在左、对应数值在右，两个数值共用右边界，不再显示静态记号。
3. 本机总 token 与 API 等值作为次要读数。
4. 多日范围显示每日堆叠柱图；本周固定七格，无记录以虚线短桩区分，未来日期为空位且不是按钮。点击日期只更新图中的当日明细，主读数保持整个已查询范围。
5. “消耗构成”“按模型查看”默认折叠。构成包含三段横条、非缓存／缓存／输出计数与输入缓存命中率；两种比例的分母分别为总 token 和输入 token。

删除旧的用量／构成／详情／区间页签以及独立日期表单，不再保留两套查询范围。构成折叠标题不重复总 token。参考套餐、双口径拆分、ModelDial 来源、价格与口径说明集中到设置中的“口径与来源”。

## 时间编辑

今日从本地 00:00 至查询时刻，本周从本地周一 00:00 至查询时刻。刷新这两个预设时更新结束时刻；自选保留已提交的绝对端点。

点击“自选”在同一浮层内展开编辑，开始／结束纵向排列。保留自绘日历和秒级时间、5min／10min／30min／1h 快捷时长；两条独立滑轨收进“精细调整”。所有编辑均为草稿，点击“应用”才提交并收起编辑器。再次点击“自选”可收起编辑器，不提交草稿。

读取新范围期间保留上次成功结果和其真实范围；过期请求及与当前精确端点不一致的响应不能覆盖结果。读取失败保留旧结果；首次失败显示不可用及重试。已有结果时刷新在区间状态行显示转圈，旧数字及原结果时间保持不动；首屏有骨架。

## 四项读数的含义

本机额度估算仍按相同模型集合分别计算 Token 和 API 比例，显示最小至最大参考范围，不平均、不叠加，不宣称真实扣量一定在范围内。无参考套餐时主读数提供“选择参考套餐”入口；无可比基准、无记录和部分模型明确区分。较长范围按上下界分组换行，不缩小主数字来容纳并排读数。

账号变化来自所选范围内的官方成功采样，单位是周额度百分点，包含其他设备。不把它叫作本机实际扣量，也不将它与本机估算的差额归因给其他机器。缺少两点时不可用；部分覆盖展示真实采样端点；采样间断、跨重置、计数校正和历史存储问题保留明确提示，不能填零。

总 token、API 等值、模型、构成和日柱都使用同一个精确 `(start,end]` 区间。API 等值仍标估算或部分计价，不代表实付费用。

## 数据与性能

Helper 的 `interval.local` 增加本地日期 `start/end` 及 `daily`；保留已有 `models/eventCount/partial/issues/hasLogs`。使用同一批去重后记录，在原有精确区间过滤中归日，不为柱图再次扫描日志。日桶各模型之和必须等于区间总量，跨午夜的第一天和最后一天也只计实际选中的部分。

外层整日汇总继续保留以兼容旧界面，新主页面不使用它冒充精确区间结果。账号采样、限流、账户隔离、持久历史和 ModelDial 同步策略沿用现有链路，不增加官方请求。

## 动效与交互

沿用已有 Motion／WAAPI、短距浮出和布局过渡；时间编辑、构成、模型和设置均可中途关闭或反向。设置中更改参考套餐时，数据回包承接当前可见设置面板的高度，不让隐藏主面板抢占动画。日桶选择不发请求。减少动态效果或页面进入后台时即时完成并清理动画。
